# nixos-config

- `flake.nix` — inputs (`nixpkgs` stable, `nixpkgs-unstable`, `home-manager`) and defines one `nixosConfigurations` entry per machine, sharing the same base modules.
- `configuration.nix` — shared system config (desktop, locale, packages) used by every host. Uses `pkgs-unstable.jetbrains-toolbox` since the stable version's download URL is dead.
- `home.nix` — home-manager config for `alex` (packages, dconf, oh-my-bash).
- `hosts/<name>/default.nix` — per-machine config: hostname + anything specific to that box.
- `hosts/<name>/hardware-configuration.nix` — machine-specific, autogenerated by `nixos-generate-config`.

## Machines

- `nixos` — the original machine (Intel CPU).
- `t14` — ThinkPad T14 (AMD Ryzen AI 350).

Apply changes on a given machine:

```
sudo nixos-rebuild switch --flake ~/nixos-config#nixos
# or
sudo nixos-rebuild switch --flake ~/nixos-config#t14
```

## Adding a new machine

1. Boot a NixOS installer on the machine, partition/mount disks, then run:
   ```
   nixos-generate-config --root /mnt
   ```
2. Create `hosts/<name>/` in this repo and copy the generated
   `hardware-configuration.nix` into it.
3. Add a `hosts/<name>/default.nix`:
   ```nix
   { imports = [ ./hardware-configuration.nix ]; networking.hostName = "<name>"; }
   ```
4. Add `nixosConfigurations.<name> = mkHost ./hosts/<name>/default.nix;` in `flake.nix`.

### Note on `t14`

`hosts/t14/hardware-configuration.nix` in this repo is currently a **placeholder**
(AMD-appropriate defaults — `kvm-amd`, `hardware.cpu.amd.updateMicrocode` — but
fake disk UUIDs). It has not been generated on the real laptop yet. Before
building `.#t14`, regenerate it per the steps above and replace the placeholder
with the real file.
