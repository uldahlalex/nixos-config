# nixos-config

- `flake.nix` — inputs (`nixpkgs` stable, `nixpkgs-unstable`, `home-manager`) and wires everything into one `nixosConfigurations.nixos`.
- `configuration.nix` — system config (users, desktop, locale, packages). Uses `pkgs-unstable.jetbrains-toolbox` since the stable version's download URL is dead.
- `home.nix` — home-manager config for `alex` (packages, dconf, oh-my-bash).
- `hardware-configuration.nix` — machine-specific, autogenerated.

Apply changes:

```
sudo nixos-rebuild switch --flake ~/nixos-config#nixos
```
